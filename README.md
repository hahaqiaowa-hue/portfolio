# Portfolio Site

This folder is ready to upload to GitHub Pages as a static website.

## Files to Upload

Upload the full contents of this folder:

- `index.html`
- `styles.css`
- `script.js`
- `assets/`

You can keep the extra `project-01.html`, `project-02.html`, and `project-03.html` files in the repository, but the main site entry is `index.html`.

## GitHub Pages Setup

1. Create a new GitHub repository.
2. Upload everything inside this folder to the repository root.
3. Open the repository on GitHub.
4. Go to `Settings` -> `Pages`.
5. Under `Build and deployment`:
   - Set `Source` to `Deploy from a branch`
   - Set `Branch` to `main`
   - Set folder to `/root`
6. Save and wait for GitHub Pages to finish publishing.

Your public link will usually look like:

`https://your-username.github.io/repository-name/`

## Notes

- Do not upload only `index.html`; the `assets` folder is required for images.
- If the page looks outdated after publishing, hard refresh the browser with `Ctrl + F5`.
- If you later add a custom domain, configure it in GitHub Pages settings after the site is live.
